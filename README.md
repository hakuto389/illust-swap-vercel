# おえかきリレー（Vercelだけで動かす試作版）

## 入っている機能
- 4桁の部屋番号を自動発行
- 4桁番号で参加
- 1部屋最大4人
- 作成者が1人あたり30秒〜3分を設定
- 参加順に1人ずつ描画
- 前の人の絵を残したまま次の人が描き足す
- タイマー、次の人へボタン、全消し
- ランダムマッチングなし
- Supabaseなど外部DBなし

## 公開方法
1. ZIPを展開してGitHubの新しいリポジトリにアップロード
2. Vercelで「Add New Project」→そのリポジトリをImport
3. Framework PresetがNext.jsであることを確認してDeploy
4. 公開URLをスマホ2台以上で開いて動作確認

## ローカル起動
Node.jsを用意し、プロジェクトフォルダで次を実行します。

```bash
npm install
npx vercel dev
```

WebSocketはVercelの実行環境が必要なため、通常の `next dev` ではなく `vercel dev` を使います。

## 大事な制約（必ず確認）
この試作版は、部屋情報・参加者・描画データをWebSocket Functionインスタンス内のメモリに保持しています。Vercelは新しい接続を別のFunctionインスタンスへ振り分ける場合があり、別インスタンスに接続した端末同士では同じ部屋が見えない可能性があります。また、Functionの実行時間上限で接続が切れることがあります。

つまり、**Vercelだけ・外部DBなしの試作**であり、安定した公開運用を保証する構成ではありません。Vercel公式も、複数インスタンス間で状態を共有するにはRedis等の外部ストアを推奨しています。

まずは少人数・短時間の動作テスト用として使ってください。安定運用に進む場合は、Vercel MarketplaceのRedis等を追加するか、接続先を固定できるリアルタイム基盤を検討してください。

## 技術
- Next.js App Router
- React
- Vercel Functions WebSocket (`@vercel/functions`)
- 状態保存はインスタンス内メモリのみ
